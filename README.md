## 찐로: 나만의 진로탐색 서비스(GDG-강냉톤)

## 개요
- 하루의 감정 일기를 바탕으로 진로를 추천해주는 서비스

## 개발내용
- Next.Js를 활용한 Front, Back 개발
- Prisma를 이용한 DB 연결 및 관리
- Chat gpt api와 프롬프트를 통한 AI 연결
- react-hook-form과 zod를 통한 입력 값 검증

## 사용한 라이브러리
```
next
tailwindcss
typescript
react-slick
slick-carousel
lucide-react
react-chartjs-2
react-hook-form
zod

KoPubWorldBatang (누누사이트 무료폰트)
Nanum_JungHagSaeng (누누사이트 무료폰트)
Pretendard (누누사이트 무료폰트)
```
